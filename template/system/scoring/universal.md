# Universal scoring dimensions (rubric v1)

Five dimensions, each 1–10. Three universal (here), two from the playbook's catalogue entry. Evidence first, number last: tick the checklist with an evidence path or dated source per tick, then derive the score. A tick without evidence does not count.

**Score derivation:** count ticks → 0–1 ticks = 2 · 2–3 = 4 · 4–5 = 6 · 6–7 = 8 · 8 = 10. Adjust ±1 with a written reason. Never score from impression.

Write to `scores/round-N.md` (cap 80 lines): per dimension the checklist with evidence, the score, Δ vs previous round and why, then the average and the steering verdict per `system/gates.md`.

## Value — how much does this matter if it works?

- [ ] A named person/segment has this problem today (source)
- [ ] They currently pay (money or time) to solve or endure it (source)
- [ ] The outcome is measurable (what number moves)
- [ ] B personally wants the outcome (IDEA.md says so or triage asked)
- [ ] It still matters in 12 months (source or reasoning)
- [ ] It compounds with something B already has (asset, audience, skill)
- [ ] The downside of not doing it is real (stated)
- [ ] Panel's value objections resolved

## Feasibility — can it be done with what we have?

- [ ] Every required capability exists in `tools/current.md` or is named with a source
- [ ] No dependency on access we don't have (data, API, permission, people)
- [ ] Riskiest assumption is testable within the prototype budget
- [ ] Comparable thing has been built/done by someone (source) or a reason why not
- [ ] Legal/regulatory path is known (source) or irrelevant (reasoning)
- [ ] B's time required is stated and under the quality bar's limit
- [ ] No step requires a human gate we expect B to refuse
- [ ] Panel's feasibility objections resolved

## Effort — what does it cost? (inverted: 10 = cheap)

- [ ] Total token estimate within the triage budget line
- [ ] Money spend ≤ what IDEA.md's quality bar allows (or zero)
- [ ] B's hands-on time ≤ 2 hours per stage
- [ ] No new accounts/sign-ups needed, or ≤ 2
- [ ] Calendar time to Review ≤ 4 weeks
- [ ] Ongoing cost after done stated and acceptable
- [ ] Exit/shutdown cost stated and small
- [ ] Panel's cost objections resolved
